\section*{Code availability}
All code for data preparation, construction of the frozen test sets, model evaluation, statistical analysis and figure generation is available on \href{https://github.com/HawkFranklin-Research/tab-r1-experiments}{GitHub (HawkFranklin-Research/tab-r1-experiments)}. Because the repository includes per-patient predictions for every model and test set, all reported statistics, figures and tables can be regenerated without refitting any model.
