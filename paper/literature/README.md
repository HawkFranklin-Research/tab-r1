# Manuscript literature collection

## First-stage shortlist

`manifest.tsv` is the machine-readable collection table. `collection_shortlist.md`
is its readable view. The last column maps each source to an intended manuscript
section. This collection was assembled on 2026-10-02 using primary web sources,
publisher records, PubMed/PMC, conference proceedings and arXiv.

The shortlist contains 40 sources: 26 already in `paper/references.bib` and 14
proposed additions. Two existing sources are official TabFM web/software resources,
not research papers. Retaining existing entries here does not certify their current
use in the manuscript. This is a targeted shortlist, not a systematic review.

## Revised-report Evidence

`reusability_evidence_table.md` and `reusability_evidence_table.tsv` contain
finding-level evidence for the revised `paper/reusability_report.tex`. Each row
keeps dataset sizes, evaluation settings, metrics, source locators and proposed
manuscript use together. `evidence_review_coverage.tsv` records source hashes,
availability and review scope. `claim_evidence.tsv` is a working mapping, not a
completed certification of the report's existing sentences.

`evidence_inventory/` contains automatically retrieved numerical passages for
further review, not independently verified results. Regenerate these artifacts
with `python paper/literature/build_reusability_evidence.py`. This reads literature
and manuscript files only; it neither runs models nor edits experiment artifacts.

Correct-source full texts remain unavailable for L05, L15, L31, L37 and L38.
Figure/supplement audits remain partial even for available texts. Do not use
quarantined `wrong_source` files as evidence.

## Original Screening Fields

- `relevance_note` is a short paraphrase of an abstract or source description, not
  a quotation or a completed claim audit.
- `comparison_limit` records what the source must not be used to establish.
- `source_url` gives a publisher, conference, repository or bibliographic landing
  page for collection. It does not imply an unrestricted PDF download is available.
- `screening_status` distinguishes new abstract/source screening from existing
  bibliography entries awaiting individual citation audits.
- `year` is the selected publication year. Herrmann et al. is assigned its 2021
  journal issue year despite online publication in 2020. Sisk et al. similarly uses
  2021 rather than its 2020 online date. Preprints use first submission year.
- `doi = NA` means no DOI has been verified for the selected edition. The stable
  source URL remains available; no DOI has been invented.
- Abstract screening is not page-level verification. No source is yet certified
  to support an exact sentence in the manuscript.

Prioritize the new Discussion sources L01-L12, the existing diagnostic sources

The clinical comparison in L01 uses its 2026 published journal version, not the
superseded medRxiv identifier. The two TabPFN technical reports remain explicitly
labeled preprints. The TabPFN-3 report is not a TabFM source.

## Storage for subsequent stages

```text
paper/literature/
  manifest.tsv
  collection_shortlist.md
  pdfs/                 # Lawfully accessible paper PDFs
  txt/                  # Extracted text with matching source IDs
  notes/                # Individual full-text and citation audit notes
  official/             # Archived software/model documentation without paper PDFs
  visual_review_status.tsv # Per-source completion state for the figure/table pass
```

The review proceeds in two passes: first download all openly available full texts
and extract their text, equations, tables and captions; then revisit each source
figure by figure and table by table. During that second pass, record any numeric
values that appear only in plotted images in the matching source note, with page,
figure/panel, units and whether a value is printed or visually estimated. Do not
present a visual estimate as an exact value. Include this figure-value review in
the continuing literature protocol for this manuscript.

`visual_review_status.tsv` is generated by `build_visual_review_status.py`.
It deliberately labels sampled visual notes as partial until every figure and
quantitative table in the source has been reviewed. A PDF or extracted text file
being present is not equivalent to completing that review.

`claim_evidence.tsv` now records candidate manuscript locations, current sentences,
source findings and supporting passages. Its separate `claim_verdict` field keeps
pending sentence-level adjudication distinct from source-finding verification.

## Citation roles

Introduction references establish the promise of tabular foundation models and
the biomedical evaluation problem. Results references identify datasets and
necessary context; our artifacts provide the primary results. Methods references
justify algorithms, scoring and reporting choices. Discussion references put our
results alongside multiomics benchmarks, case-mix effects, cross-study validation,
informative observation and negative transfer.

Survival C-indices and integrated Brier scores must not be numerically ranked
against our fixed-horizon ROC AUC. Combining modalities is not the same experiment
as pooling cancer cohorts. EHR informative observation is not equivalent to our
structural-zero representation. General negative-transfer and shortcut-learning
papers motivate hypotheses, not proof of the mechanism in our evaluated models.
